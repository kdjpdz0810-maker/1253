[그림파일 변환기 - exe 자동 빌드 프로젝트]
1) GitHub 에 새 저장소(Repository)를 만들고 이 폴더의 파일을 모두 업로드
   (.github 폴더 포함)
2) 저장소의 Actions 탭 > "Build Windows exe" > Run workflow
3) 5~10분 후 완료되면 Artifacts 의 PictureConverter 를 다운로드
   - PictureConverter.exe        : 설치 없이 바로 실행(포터블)
   - PictureConverter_Setup.exe  : 설치 프로그램(바탕화면 바로가기 포함)
